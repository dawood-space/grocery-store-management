GROCERY STORE MANAGEMENT SYSTEM - VS CODE PROJECT

FILES:
store_backend.py - inventory, cart, stock, recursion, billing
main_app.py - Tkinter desktop interface

RUN IN VS CODE:
1. Extract these files into your project folder.
2. Open that folder in VS Code (File > Open Folder).
3. Open Terminal > New Terminal.
4. Type: python main_app.py
   If Python is launched with the py command on your Windows computer, use: py main_app.py
5. Enter product names exactly as displayed (case-insensitive).
6. Enter whole-number quantities.
7. Click Add to Cart, Preview Bill, and Checkout.

SAMPLE DEMONSTRATION:
Rice, quantity 2 -> Rs.120.00 before GST.
Milk, quantity 3 -> Rs.90.00 before GST.
Subtotal Rs.210.00, classroom demonstration GST at 5% Rs.10.50, total Rs.220.50.

IMPORTANT:
- GST 5% is an educational example only; actual GST varies by product.
- Stock and bills are stored in memory only and reset when the app is restarted.
- No external packages are required for normal Python installations with Tkinter.
- Take your own screenshots after running the project in VS Code.
